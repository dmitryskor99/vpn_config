# vpn_config
Конфиги и скрипты для VPN
Требования и совместимость
Параметр	Требование
ОС	Ubuntu Server 22.04 LTS, кодовое имя jammy
Проверенная версия ОС	Ubuntu 22.04.5 LTS
Архитектура	amd64 / x86_64, 64 бита
Права	Запуск от root, в том числе через sudo bash
Оболочка	Bash
Управление пакетами	APT
Управление службами	systemd
Сеть	Работающие DNS и HTTPS-доступ к репозиториям Ubuntu, Docker и Docker Hub
Состояние сервера	Предпочтительно свежая установка ОС без существующей контейнерной инфраструктуры
